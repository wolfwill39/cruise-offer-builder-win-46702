## About em

em is an internal web-based campaign builder for cruise e-shot production. It brings together UTM generation, export tooling, and campaign packaging so teams can prepare structured campaign assets without moving between separate tools.

The project is geared toward workflows where consistency matters across campaign files, asset folders, and summary outputs. By keeping those pieces aligned in one place, it helps reduce manual setup and makes repeat campaign preparation easier to manage.
